# Grade Predictor (Fullstack)
Backend: Node/Express + Prisma + JWT + SSE  
Frontend: React (JSX) + React Router  
ML: Python CLIs in /ml (train.py, predict.py)

## Dev
1) cd server && npm install && cp .env.example .env && npx prisma migrate dev --name init && cd ..
2) cd client && npm install && cd ..
3) npm run dev   # run backend and frontend separately
